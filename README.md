# Pawgress
A helpful study bot for discord that acts as a pet for you and your study group! The bot will track your time studying and will reward you for doing so. You may then use your rewards to keep your group pet alive and happy.

## Installation
To install, you must have an up-to-date version of python and the libraries: discord and dotenv, though most users will use their machines to access a bot being hosted on a separate machine. TO install the bot to your server, use the link: https://discord.com/oauth2/authorize?client_id=1562131394514255912&permissions=8&integration_type=0&scope=bot

## Build
No build of the application is needed in order to run the Discord Bot as Pawgress runs on directly the Python Interpreter and will most likely be accessed remotely, not requiring users to locally host the bot to begin with.

## Run
If you want to run the bot for yourself on your local macine, run the python file locally. Normally you should be able to access the hosted bot by downloading it into your discord server.
### Run commands:
!help - bot will list commands
!create - will create a new study bot for your group
